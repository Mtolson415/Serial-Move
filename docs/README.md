# Learning and documentation index

Start with the [project README](../README.md), then [current review and completion plan](PROJECT-REVIEW.md).

## Read before building
Explain the selected design, alternatives, prerequisites, exact tested commands, expected outputs, troubleshooting, security permissions, cost, and recovery. Update the root README and this index whenever these change.

## Reusable components and APIs
Prefer existing tested project code, maintained official SDKs, and version-matched owning-repository examples. For each reused component record source URL, version/commit, license/notices, adapted files, reason selected, minimal example, error cases, and test evidence. API records include authentication, data destinations, limits/cost, timeout/retries, and schema/version. Official examples remain candidates until project acceptance checks pass.
